GEMA WINDOWS TEST PACKAGE v1
==============================

1. Extract this ZIP.
2. Double-click RUN_GEMA.bat.
3. Test the modules from the left-hand desktop navigation.

The build demonstrates the Stage 2 foundation plus the integrated investment
workflow. Data created during testing is saved in the data folder.

This is a DEVELOPMENT TEST BUILD, not a production deployment. It does not
implement real payments, identity verification, production authentication,
or production-grade security.

Recommended test journey:
Business Directory -> Marketplace -> Industrial Intelligence ->
Investment Projects -> Investor Matching -> Deal Workflow -> Analytics.
